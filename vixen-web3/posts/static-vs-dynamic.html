why "just read the disassembly" is a scam

for a while i refused to actually run anything in a debugger. felt like cheating. real reverse engineers just read the disassembly and figure it out in their head right? that's what everyone online acts like anyway.

wrong obviously. some behavior only shows up at runtime and no amount of staring at static output is gonna reconstruct what a program does when a value changes based on something external. timing, environment, whatever it's checking. you can't out-think that from a wall of text.

these days i open a debugger almost immediately. saves hours. anyone still doing pure static analysis for everything is kind of coping ngl
